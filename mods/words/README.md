# Word Set Templates

`classic.txt` is the playable lowercase-only version of TypeKart's bundled word list.

Edit a copy when making a custom word set. Rules:

- One word per line.
- Lowercase ASCII letters only.
- No punctuation, spaces, numbers, or capitalization.
- At least three unique words.

Run with:

```sh
typekart play --word-set-file ./mods/words/classic.txt
typekart host --word-set-file ./mods/words/classic.txt
```
